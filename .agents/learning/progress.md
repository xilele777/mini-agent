## 当前限制

- 完成与暂停的选择依赖模型、提示词和工具描述；已有用例不代表所有自然表述都已验证。
- todo 条目只有 `id/title`，归属当前会话；轮结果持久化，同一会话以独占锁限制写入者。崩溃遗留锁仍需核查原进程退出后人工清理。
- 原始历史完整保存，主／子请求按文本保守估算检查窗口；主轮按需裁剪旧轮并尝试有界摘要，摘要有损且不保证语义无遗漏。主／子／摘要／重试现共享总次数、时间与 token 账目；缺 usage 保留估算，服务端精确计数及严格生成上限不由本地估算保证。总时限为协作式中止，清理和可靠保存可继续收尾。
- 受控文件工具统一项目范围与敏感路径，编辑／新建进一步拒绝链接路径、校验 SHA-256 并逐次批准；只支持最大 1 MiB 的 UTF-8 修改。检查到提交间仍有竞态，shell 依赖批准，不构成完整沙箱；脱离进程树的后台服务不能保证清理。
- 子 Agent 当前同步且只读，固定六次请求并保留最后一次总结；不并行、不持久化、不共享 todo，也不支持嵌套批准或递归委派。
- 决策笔记已建立对应设计理由。后续变更优先更新所属笔记，避免将这些摘要扩展成第二套设计文档。
