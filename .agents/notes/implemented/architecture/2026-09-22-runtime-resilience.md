# Agent Note: 每个用户轮共享取消、传输预算和脱敏运行事件

Status: implemented

## Problem

主轮与摘要原先共享局部次数，委派另有六次额度，SDK 禁用重试。一次委派或网络失败的成本不能反映在主轮总额中；只有单次请求及命令超时，批准等待没有总截止时间。普通终端文本也难以关联同一用户轮的摘要、子任务、失败尝试和 token 消耗。

## Decision

[run-control.ts](../../../../src/run-control.ts) 为每个真实用户轮建立 RunControl；[session-runner.ts](../../../../src/session-runner.ts) 在初始检查点保存前创建并在 finally 释放。CLI 生命周期信号连接本轮控制器，轮内总时限使用单调时钟并包含批准、摘要、委派、退避、工具和检查点等待。等待下一条用户输入不占轮预算。外部取消为 cancelled，总时限为 budget_exhausted；单请求超时在有限重试后为 failed。取消或超时都不撤销副作用，清理及可靠保存可在截止后继续完成。

每次实际传输之前预留一次请求与“输入估算 + 输出上限”，包括失败尝试、摘要、子任务及重试。正常报告的有效 usage 替换本次预留值；缺少或非法 usage 保留估算并单独计数，失败请求也不记零。实际 usage 超总额时停止后续动作。默认全轮 24 次、200000 tokens、600000ms；主／摘要局部十次、子任务局部六次继续限制逻辑请求，不包含同一逻辑请求的传输重试。子任务最终总结仍须取得总预算。摘要开始前需要至少两次剩余额度；后续重试可能耗尽余量，不能额外借出回答额度。

重试只有 RunControl 一层，SDK 仍为 maxRetries=0。连接错误、单请求超时、HTTP 408/429/500/502/503/504 在零 chunk 时最多重试两次，以 500ms 起指数退避、上限 10000ms。任意 chunk（含角色、工具参数或 usage）交付后不重试；认证、协议、上下文、批准和工具执行错误不重试。每次重试重新预留预算，取消可打断退避。只重试当前传输，不重跑主循环已确认动作。

[telemetry.ts](../../../../src/telemetry.ts) 定义请求、重试、工具、批准与轮结果的类型化事件，驱动终端运行提示及每会话 trace.jsonl。每条轨迹携带 sessionId、turnId、递增序号和时间；子任务另用生成的 taskId，同轮工具用递增动作编号。请求记录范围、预留／结算 tokens、actual/estimated、结果及耗时；轮末汇总请求、已启动工具、总时间和 token。工具名只接受内置白名单，扩展工具记 other；不记录用户／模型正文、参数、命令、路径、工具结果、调用方原始 ID、API 配置或异常正文。Zod 运行时白名单再次丢弃多余字段。

轨迹为追加诊断副本，不作为恢复来源；写失败只警告一次并禁用本轮轨迹。快照的原子检查点仍必须等待，保存失败照常终止。原始快照和正常交互输出仍含任务内容，不能当成脱敏资料分享。恢复不读取或重放轨迹；新输入建立新账本。沿用[会话恢复](2026-09-21-atomic-session-storage.md)、[上下文及摘要](2026-09-05-bounded-conversation-context.md)、[只读子 Agent](../feature/2026-09-19-isolated-readonly-subagent.md)的边界。

文件读取和目录搜索接收同一信号，readFile 可中止，目录遍历逐项检查。注册表执行包装不得吞掉取消；子请求总预算错误向主轮传播。started 检查点已提交后才收到取消时按 uncertain 收尾，避免把已开始状态错误转换为 not_executed；命令的原始清理报告仍保留。

## Alternatives considered

- 开启 SDK 内置重试：实现少且覆盖常见网络错误，但内部尝试无法与委派、摘要共同预留总额，也难以对已交付片段统一限制；保留 SDK 零重试，在共享传输包装层负责。
- 只在主循环累计成功 usage：改动较少且统计简单，但漏掉失败尝试和无 usage 请求，预算耗尽后才发现成本；采用发送前预留、返回后结算，接受估算偏保守。
- 用 JSONL 同时做恢复事件源：可以统一审计与恢复，但需要新重放协议和事件迁移；已有快照明确动作窗口，继续以快照恢复、轨迹作可丢诊断副本。
- 完整记录请求与结果后用正则脱敏：调试上下文最丰富，但密钥和私有内容形态不可枚举；采用白名单元数据，接受必须结合本地快照才能调查正文细节。

## Consequences

同一用户轮的主／子／摘要／重试有统一可观察账目，批准、模型和命令等待有共同停止信号。代价是故障请求按完整预留估算可能较早停止，轨迹使用同步短行写入增加少量 I/O，且元数据不能复原对话。

输入估算并非供应商 tokenizer；usage 缺失、服务端忽略输出限制或计量延迟时不承诺精确费用硬上限。取消是协作式的，不能抢占阻塞 JavaScript 的同步计算或任意不遵守信号的工具；截止后会在下一个调度边界停止，命令树清理继续沿用已验证的平台边界。JSONL 不做 fsync，也不作为断电保证；本阶段不增加轨迹轮转和跨进程执行。
